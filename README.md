# 🏨 Hotel Reservation Cancellation Prediction

## Project Overview

This project predicts whether a hotel reservation is likely to be cancelled using Machine Learning techniques. The objective is to help hotels improve revenue management, optimize resource allocation, and support better decision-making by identifying bookings that are at risk of cancellation.

---

## Problem Statement

Hotel reservation cancellations can result in revenue loss, inefficient room utilization, and operational challenges. The aim of this project is to develop a machine learning model that predicts whether a hotel reservation will be cancelled, enabling hotels to take proactive measures.

---

## Dataset Information

- **Dataset Name:** Hotel Reservations
- **Total Records:** 36,275
- **Total Features:** 19
- **Target Variable:** `booking_status`

**Target Classes:**
- Not_Canceled
- Canceled
